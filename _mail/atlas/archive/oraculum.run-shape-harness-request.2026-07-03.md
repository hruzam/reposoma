## Pattern A — task-run (execution-shaped) · Vara in charge

For runs where verdicts are settled and work is a grind of well-defined units.

1. Architect (Houston/Flight) hands Vara a gated task list — plan authority stays with the architect.
2. Vara loop per task: classify → route (Delta surgical / Vector mid / Trajectory senior) → verify output against the task's gate criteria → checkpoint (commit + task ledger line).
3. Escalation rule: anything requiring judgment beyond stated criteria goes UP, never absorbed.
4. Human hears at: kickoff, blocked-escalations, completion report.
5. State discipline: pulse thin, ledger append-only, commits per checkpoint, no pushes.

## Pattern B — synthesis-run (Oraculum-shaped)

For runs that are judgment-dense: research processing, cross-measurement, derivation-locked artifacts. The anatomy below is the worked run of 2026-07-02 (nabla-lab, Atlas №2), generalized:

0. **Wake protocol:** pulse → flag → handoff → working docs. Do not re-derive what is locked; locks are honored, not re-litigated.
1. **Contract first:** named human gates (this run had exactly three), token reserve (≥30%), write boundaries, commit-never-push.
2. **Mechanics pushed down, judgment held in the seat:** shell → Delta; bulk reads → Explore; online research → Epoch; math derivation → Color. The seat's asset is accumulated context — never serialize the synthesis into a subagent.
3. **Blind fan-out:** heterogeneous legs (online-depth / offline-math / cross-vendor), blind to each other, one researcher sees all forks. Each leg writes its own dated artifact.
4. **Cross-measure (the seat's own work):** convergences (independent agreement = strongest signal), divergences + explicit rulings, corrections registry, per-fork verdicts marked pending-gavel.
5. **Targeted follow-up only for holes the cross-measure itself exposes** — not general curiosity (this run: one follow-up, two questions, both load-bearing).
6. **Derivation-locked artifact writing:** every downstream artifact derives from the WHOLE processed corpus, never raw drafts piecemeal.
7. **Adversarial gate before crossing:** Janus pass; verdict REVISE means revise-applied-same-day, documented in each artifact header; conditions become mandatory sections (null-model gates, named silent steps).
8. **Thin mount checks:** extraction by read-only agents; comparison judgment stays in the seat; sibling canon (fences) is honored, findings that contradict a lock go to the gavel queue as reality deltas.
9. **One consolidated gavel queue** at close — everything awaiting the human in one numbered place.
10. **Degrade-don't-stall:** failing legs get one bounded retry then park with verbatim logs; the run continues on remaining legs, degradation flagged.
