# _mail/ — the monkey's ephemeral mailbox (NON-CANONICAL)

Temporary, human-facing notes from the temple architect (@Houston, reposoma basement) to the
operator — *"so the monkey does not forget something important"* while sitting on many chairs.

**Nothing here is load-bearing or canon.** Canon lives in `temple/decisions/`, `raw.guides/`, and
each project repo. These notes are **gitignored on purpose** (only this README + `.gitignore` are
tracked) and are **safe to `rm -rf` once drained**.

Cinderella rule: a note expires — extract what matters into its real home, shift it there, then
delete the note. When nothing is left to extract, the folder goes back to pumpkin.
