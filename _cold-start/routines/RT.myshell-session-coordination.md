# myShell — multi-session coordination entry

Personal, uncanonical entry card. The reusable coordination procedure now lives in
~/reposoma/.majkee/.germline/programs/session-coordination/CONTROLLER.md and its
selected function. This card owns myShell's native role choices and entry wording,
not a second recipe or function index. Keep it in routines/ after use.

## Coordination frame

```text
Majkee / session heads → myShell (one stream, cross-session overview)
                         ├─ session A: liaison · preprocessor · Oraculum · Astrobley
                         ├─ session B: liaison · preprocessor · Oraculum · Astrobley
                         └─ session C: liaison · preprocessor · Oraculum · Astrobley
```

Each row is a distinct retained support team for one selected session. Specialists
are attached to that session, not automatically pooled across all rows. Bind/brief
members when requested or needed, then reuse them while natively addressable.
Attached does not mean all are running or called on each input. Planned slots
must not be described as already instantiated or briefed.

myShell dispatches and integrates. A liaison holds its session map and source context;
it may recommend which member should examine a question. It is not the project head
or an autonomous team dispatcher. The real cSharp retains its gate, STATUS and pen.

## Caller-supplied native bindings

| Program role | Default native assignment | Authority |
|---|---|---|
| context-liaison | separate session-bound researcher, Terra/high where available | read-only contextual intake and continuity |
| input-preprocessor | another researcher, Terra; a lighter available reader when sufficient | read-only extraction of noisy input and source slices |
| strategic-thinker | session-bound custom oraculum, Astra at its deployed effort | bounded analysis-only consultation |
| development-adviser | session-bound custom astrobley | practical judgment; read-only unless separately assigned authorized file work |
| factual-researcher | scoped native researcher on demand | primary-source evidence for a named gap |

Check actual native definitions and availability. These are assignment defaults, not
new global role files or a model guarantee. The liaison and preprocessor have different
responsibilities; combine them only as an explicit small-session choice. Bind thinkers
and advisers per session; sharing one across sessions is an explicit exception.
Preserve each native role's return and pen contract. No role grants operator authority.
