# SEED — the coherence homeostat

## CORE REFRAME  (#grep)
- #not-hooks — these are NOT hooks. Hook = INTERRUPT (fires on an EVENT / what the agent DOES).
    These = HOMEOSTAT (act on a STATE / what the agent IS: its coherence). Reflex, not interrupt handler.
- #one-operation-three-rates — anchors/lighthouses/harbour are ONE operation at three sample-rates:
    "re-ground volatile context against durable files" (= truth-lives-in-files, read backwards).
      lighthouse = sampled CONTINUOUSLY  (durable index always in view)
      anchor     = sampled ON-DRIFT      (catch only past the radius)
      harbour    = sampled ON-EXHAUSTION (discard volatile context, rebuild from shore)
- #one-signal-three-thresholds — don't build three mechanisms; build ONE coherence signal with three
    thresholds keyed to distance-from-coherence. (Same tiered shape as #cost-gradient.)

## THE THREE  (theirs; reframed)
- #anchor — has a RODE: permits FREE movement within a radius, catches only at the limit.
    #anchor-licenses-drift — it does NOT oppose drift, it LICENSES it. The catch is what makes bold
    wandering safe → karpathy floor / honest regime ARE anchors. "A mind that can't anchor daren't think boldly."
    (This is the crtv extension @majkee asked for.)
- #lighthouse — continuous orientation beacon = pulse / CLAUDE.md instant header → small list → local index (ini).
    Mostly-shared, known-by-convention (#known-to-all-distributed-to-none). Not all agents need it; useful when they do.
- #harbour — #harbour-is-sleep-not-shipwreck. Reframe from emergency ("nearly exhausted/stuck") to CADENCE:
    harbour BEFORE exhaustion, like nightly sleep, not collapse. "small past reconstruction" = MEMORY CONSOLIDATION
    (the compressed residue that survives the night). NOTE: every handoff this thread WAS a harbour log.
