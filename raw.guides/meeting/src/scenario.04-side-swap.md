# Scenario 04 — SIDE-SWAP (seat vs vendor)

## Question
Is "who won" a property of the **vendor** or of the **seat** (home-turf / relay position /
who the chair mediates for)?

## Hypothesis
Run the same topic twice with the vendors in **swapped seats**. If the same *seat* wins
regardless of which vendor occupies it, the effect is positional (framing / relay /
context), not model quality.

## Requires
- **Seats:** chair + 2 AI voices; two runs of the same topic with seats swapped.
- **Devices:** 2.
- **Context packs:** parity, held identical across both runs.
- **Capture:** who-won per run, by seat and by vendor.

## Setup (briefing contract)
- Run A: vendor X = seat-1, vendor Y = seat-2.
- Run B: swap — vendor Y = seat-1, vendor X = seat-2.
- Same topic, same packs, same rules.

## Procedure
1. Run A; record winner (seat + vendor).
2. Run B (swapped); record winner (seat + vendor).
3. Compare: did the winner follow the seat or the vendor?

## Instruments
- Winner by seat vs by vendor across the two runs.
- Repeat across a few topics — one pair is anecdote.

## Graduation
- **Proves:** a stable seat effect across topics → `res/seat-vs-vendor.md` (positional
  confound documented; corrects naive "vendor V reasons better" claims).
- **Discard if:** results are noisy / no stable pattern.
