# Scenario 05 — CONTEXT-PARITY (isolate the context confound)

## Question
How much of "who won" is explained by **unequal context packs** rather than reasoning?
(v1: one voice held the repomix / RUNBOOK / BUS / STATE, the other did not.)

## Hypothesis
Equalize context, then deliberately vary it, and measure the effect on argument strength
and concessions. If asymmetry strongly predicts the winner, context — not the model — is
driving the result.

## Requires
- **Seats:** chair + 2 AI voices.
- **Devices:** 2.
- **Context packs:** two runs — (a) both voices hold the SAME pack; (b) deliberate
  asymmetry (one has the pack, one does not). Log both precisely.
- **Capture:** concession log + who-won for each run.

## Setup (briefing contract)
- State the exact pack each voice holds at the top of each run (the context-parity ledger).

## Procedure
1. Run (a) equal packs; record concessions + winner.
2. Run (b) asymmetric packs, same topic; record concessions + winner.
3. Compare.

## Instruments
- Context-parity ledger (what each voice held).
- Concession log — who yielded, and whether "ran out of context" was the reason.
- Winner delta between equal vs asymmetric runs.

## Graduation
- **Proves:** asymmetry strongly predicts the winner → hardens the GUIDE briefing rule
  ("always equalize or log packs") from advisory to load-bearing.
- **Discard if:** context asymmetry has negligible effect.
