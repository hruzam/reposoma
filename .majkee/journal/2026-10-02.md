# 1 `~/majkee/tasks/2026-10-02/tomas-formular` — PDF form tooling (CONV)

Context: filling an official CZ PDF form for Tomas. Found on this box: `qpdf`, `pdftotext` (poppler).
Missing: any Python PDF lib, `pdftk`. Task itself runs from a local venv; below is what's worth
having system-wide for this recurring kind of job.

## 1.0 install tips (Manjaro / pacman)

- [ ] `python-pymupdf` — read/fill AcroForm fields, write text onto flat (non-form) PDFs, render pages to PNG for visual check. Main workhorse.
- [ ] `python-pypdf` — lightweight AcroForm field listing + filling; good second opinion when pymupdf output looks off.
- [ ] `pdftk` — one-liner CLI: `dump_data_fields`, `fill_form data.fdf`, `flatten`. Fast for scripted fills.
- [ ] `ocrmypdf` + `tesseract-data-ces` — scanned forms (images only) → searchable PDF with Czech OCR, so fields can be located by text.
- [ ] `img2pdf` — jpg/png → pdf losslessly (covers the "jpg → presentation/serial" use case from AGENTS.md).
- [ ] optional: `xournalpp` — manual GUI annotate/sign when a form must be hand-touched.

One-shot: `sudo pacman -S python-pymupdf python-pypdf pdftk ocrmypdf tesseract-data-ces img2pdf`
Alt (no system Python libs): `uv venv && uv pip install pymupdf pypdf` per task folder.
