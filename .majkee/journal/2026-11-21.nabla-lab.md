## Restart: elastic tmux shell windows, no automatic CLI launches

Run on office after SSH/`tso` is available. This block creates only missing
components; it does not kill sessions or type into panes. Existing viewers must
already belong to the expected group. "Elastic" here means per-window
`window-size latest` and `aggressive-resize on`, so sizing follows the most
recently active client rather than a fixed 107×59 capture. This is the proposed
restart configuration, checked against installed tmux help; it has not been
applied to the live windows in this preservation turn.

```bash
bash <<'SH'
set -eu
base=nabla-lab
if ! tmux has-session -t "=$base" 2>/dev/null; then
  tmux new-session -d -s "$base" -n controller -c "$HOME/reposoma/.majkee"
fi
for window in controller claude codex; do
  case "$window" in
    controller) workdir="$HOME/reposoma/.majkee" ;;
    *) workdir="$HOME/nabla-lab" ;;
  esac
  if ! tmux list-windows -t "=$base" -F '#{window_name}' | rg -Fxq "$window"; then
    tmux new-window -d -t "$base:" -n "$window" -c "$workdir"
  fi
  tmux set-option -w -t "$base:$window" automatic-rename off
  tmux set-option -w -t "$base:$window" window-size latest
  tmux set-option -w -t "$base:$window" aggressive-resize on
  viewer="view-lab-$window"
  if tmux has-session -t "=$viewer" 2>/dev/null; then
    group=$(tmux display-message -p -t "=$viewer" '#{session_group}')
    if [ "$group" != "$base" ]; then
      echo "STOP: $viewer belongs to a different group: $group" >&2
      exit 1
    fi
  else
    tmux new-session -d -t "$base" -s "$viewer"
  fi
  tmux select-window -t "$viewer:$window"
done
tmux list-sessions -F '#S group=#{session_group} windows=#{session_windows} current=#{window_name}'
tmux list-panes -s -t "$base" -F '#W pane=#{pane_id} cmd=#{pane_current_command} cwd=#{pane_current_path} size=#{pane_width}x#{pane_height}'
SH
```
