# 2. RUBY - small ping-pong with cartan(codex) 
```
Ruby can parse YAML cleanly through its standard Psych
  library. But for this repository, where the control path is
  already zsh → Python, Ruby would add a third runtime
  without much benefit.

  The cleaner boundary is:

  zsh command → Python helper → yaml.safe_load() → JSON → jq/
  zsh

  For example:

  python parse_frontmatter.py "$card" | jq -r
  '.project, .kind, .assoc[]'

This lets scripts react reliably to fields such as kind,
  project, origin, and assoc without trying to parse YAML in
  zsh. yaml.safe_load() also avoids unsafe YAML object
  construction. Ruby becomes useful if we begin writing Ruby scripts or
need a Ruby-based toolchain. For the existing harness,
PyYAML 6.0.3 already provides the right library, so I would
not install Ruby solely for frontmatter handling.
```
