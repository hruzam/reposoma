  - =$S: the = prefix makes the session-name match exact, so cmm
    can't match cmm-invariance.
  - send-keys vs passing the command: send-keys types into a live
    shell, so the window survives when the agent exits. Passing
    new-window ... 'claude ...' closes the window on exit unless
    you also set tmux set -g remain-on-exit on.
  - Renaming: a window given -n is not auto-renamed by the running
    process. Turn it off explicitly with tmux set -w -t 
    "${S}:oraculum" automatic-rename off.
  - Panes instead: split a window with tmux split-window -h -t 
    "${S}:atlas-ui" -c "$D" (-h side by side, -v stacked).

  2. Attaching: flags and what you can vary
