Philosophical/process proposal; no implementation or project decision.

The useful device helps Majkee understand and own the next commitment. Faster copying succeeds
when it also reduces the work of reconstructing what happened and why.

Astrobley’s small composer is a sensible implementation candidate: ordinary files in Sublime,
optional `new`, `check`, and `render` commands, and explicit preview before manual carrying. Resolve
loading tags through existing controller tables. Keep the procedure usable by hand.

The smallest evidence distinguishing stages after interruption is:

- **Rendered:** a preserved copy of the exact prompt, with its message ID and version or digest.
- **Carried:** a dated human report identifying that version and its destination. This records the
  carrier’s observation; it cannot prove recipient acceptance.
- **Accepted:** an explicit recipient response referring to that request version, stating the
  bounded task accepted and any missing prerequisites.

These can be short entries in the exchange, written by its integration owner with attribution.
They describe message history; project STATUS still owns project progress. If a receipt is absent,
the stage remains unknown. Reconcile that uncertainty before repeating delivery where duplication
matters. Acceptance itself does not supply missing authorization.

For a cold start, provide the question, scope, open message reference, and pointers to the governing
instructions and current owner STATUS. Read next actions and recovery probes there. Avoid
maintaining another copy.

Tags express addressing and loading intent. They cannot establish identity, permission, completed
reading, or acceptance. A checker can detect missing fields and unavailable local paths; only the
recipient’s actual reading can expose some conflicts or expired authority. Its return should make
those limits visible.

Challenge should name a proposition and what evidence would change it. The controller then records
what changed, why the proposition was retained, or what remains unresolved. That makes challenge
consequential without requiring ceremonial approval of every message.

One preference remains different: I would make the **whole exchange** the human’s primary reading
unit; individual packets are useful views for sending. Astrobley starts from message files. Test
which arrangement makes one interrupted sitting easier to resume.

Transport is a later, separately authorized boundary. Human-triggered tmux delivery cannot
silently expand Ovitmugen’s current role.
