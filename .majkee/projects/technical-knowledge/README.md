“Useful” means the note contains a reusable principle or a concrete reference.
It does not certify every tool or paper claim. “Unproven” includes both unknown
sources and real projects whose practical value remains unevaluated. “Crap” rejects
specific hype claims; it also identifies noise that yielded no technical knowledge.
It does not condemn a whole paper because a post exaggerated it.
