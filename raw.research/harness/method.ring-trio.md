# Method: Ring Trio — Wander · Tag · Cooled Synth
`derived-from: larva.dev .shared method cards (2026-05-17/20) + the psychology-session prototype (vacuole/anechoic, phases 2–3 + v2 four-stream reconfig) · excavated + sat properly 2026-07-10 · tier: research/harness`
`doctrine: honesty-over-show · blind-before-grounded · gate-the-big · persist-durably (the temple)`

## The one idea
**Frame-finding.** When the structure of a problem is unknown, you cannot run
`research-pattern.md` — it needs a hypothesis to test. The ring trio *produces* the
hypothesis: heat the conceptual space (**wander**), account honestly for the metaphors the
heat throws off (**tag**), then assay everything cold (**cooled synth**). The output of a
ring is a **decision-feed for the operator, not a deliverable** — it names what survives,
what dies, and what the next ring should be.

## When to use — and not
- **Use:** pre-hypothesis. Axes are guesses; the frame itself is under test.
- **Don't:** a hypothesis exists → `research-pattern.md`. Executing a gated task list →
  `/run-task`. Synthesizing a planned multi-leg run → `/run-synthesis`.
- **Ring separation (fixed):** *frame ring* (this) ≠ *test ring* (probes on the hypotheses
  the frame produced) ≠ *deliverable ring* (cards, specs). Probes belong to a test ring —
  never smuggle them into a frame ring. Never collapse rings into one pass.

## A. Instrument 1 — the wandering step (heat)

Non-linear coordinate path, four steps. Inspired by non-linear clock calibration
(test 100N → 500N → 250N to expose gear distortion): the leap-then-bridge order exists to
break linear conversational habit.

| step | posture | what happens |
|---|---|---|
| **[A] Analyze** | coldest | establish the deterministic baseline constraint |
| **[C] Leap** | hottest | *skip the logical next step* — jump to a distant domain, extreme edge case, alien conclusion |
| **[B] Bridge** | warm | look back at A and C; construct the missing middle |
| **[D] Reality check** | cold | validate B against real constraints |

Two honest notes baked in from the prototype:
- **[D] is bounded by the same trained surface that did the heating.** It is a first pass,
  never the final word — the cooled synth (instrument 3) exists *because* of this limit.
- **Posture, not parameters.** The harness cannot shift temperature mid-run; the steps are
  stance instructions. Hold the stance shift deliberately or run separate sessions.

*Optional telemetry footer* (forward hook for a spectral/RAG feed — `reposoma.devenv`;
unwired today):
`[Wandering-Step Telemetry | leap-magnitude: low/med/high | vector-shift: domain/conceptual/technical | bridge-integrity: failed/strained/solid]`

## B. Instrument 2 — metaphor-tagging (honest accounting)

High-temperature wanders produce metaphors; without discipline, load-bearing argument and
pretty prose look identical on the page. Tag **at write-time**, while the inference state
that produced the metaphor still exists — post-hoc archaeology is unreliable.

On first introduction of a metaphor, next line:

```
> [metaphor: <name> | self-call: <load-bearing | intuition-pump | performance>]
```

| tag | meaning | removal test |
|---|---|---|
| **load-bearing** | the metaphor IS the argument | state the claim without it — if you can't, load-bearing |
| **intuition-pump** | opens the thought; claim survives removal, path to it is lost | claim survives, vividness dies |
| **performance** | prose work, not argument work — honest self-flag | removing it loses nothing structural |

Rails:
- Exactly one tag. No hybrids, no fourth tag. Per-introduction, not per-mention.
- **A wander with zero `performance` tags was not honest with itself.** Most leap-phase
  metaphors are performance; the point is marking, not suppressing.
- Do not argue with the cooled reader in advance ("you'll see why in [B]"). Tag and move.
- **Tag-vs-assay disagreement is calibration signal, not error.** Consistent over-calling of
  load-bearing = a known bias to correct for.
- **Cross-vendor caveat:** the discipline is Claude-conditioned in observation. Non-Claude
  streams may comply mechanically without self-noticing — the synth reads their tags
  critically, and their briefings paste intent rather than referencing skill cards.

## C. Instrument 3 — cooled synthesis (assay)

A separate cold pass over the wanders. Same model is fine; **temperature posture shift is
mandatory** — fresh session, or a deliberate stance switch.

**Stance: assayer.** Hold each finding to the light, decide what it weighs, record the
weight. Three postures to refuse: *cheerleader* (validating to be polite), *demolisher*
(cutting everything to prove rigor), *therapist* (treating the writer's calibration as the
subject — different mode).

**The four-bucket sort** — every finding lands in exactly one:

| bucket | meaning |
|---|---|
| **Keep** | survives scrutiny — real, actionable, or structurally clarifying |
| **Cut** | performance, over-reach, or unsafe to ship (the wander may have self-flagged it — honor the flag) |
| **Hold under observation** | plausible, untested — worth a probe *in a test ring* before promoting or killing |
| **Honest note** | undecidable from inside the inference — ship the uncertainty itself |

If a finding fits no bucket, look harder — that is laziness, not ambiguity.

**Work loop (fixed order):** read everything first (no triaging mid-read — anchoring) →
enumerate findings, no bucketing → bucket in one pass → validate every metaphor tag via the
removal test, record disagreements → write. Synth costs ≈ half the tokens of its inputs;
if it costs more, you are wandering again — stop.

**Output shape (fixed sections, keep headings even when empty):** headline structural
change (or explicit "none") · per-axis Keep/Cut/Hold/Honest · metaphor-tag validation ·
gaps the frame didn't name · phenomena marked-not-acted-on · recommendations for next ring
(concrete, scoped) · items for operator decision · closing note (most useful thing +
most overproduced thing).

Rails: no new wanders inside synth (note "worth a future wander", move on) · no new
metaphors · no manufactured closure · no pre-baking later rings' deliverables · plain prose
by design — a sentence doing prose work gets cut. **Cross-axis convergence is the headline
AND suspicious**: the same trained surface can agree with itself; mark convergence
explicitly as both signal and confound. Beautiful prose is a yellow flag — weight the most
quotable wander *more* skeptically, not less.

## D. Ring anatomy (FIXED)

```
frame (rush v1 is fine — it will be wrong in one specific way; finding that way is the point)
  → wanders: one stream per axis · blind · reading-restricted · tags inline · persisted raw
  → cooled synth: separate pass/session · four-bucket assay · tag validation
  → decision-feed to the operator → gate → next ring (frame v2 | test ring | stop)
```

- Streams never see each other's output before synthesis.
- **Heterogeneity upgrade (v2-proven):** to test whether the frame is *the model's frame or
  a frame*, run streams across tiers (Haiku/Sonnet/Opus) plus ≥1 cross-vendor leg —
  blind-leg supply per `reposoma/triangle.md`; blind protocol per nabla-lab flag lock 6.
  One cross-vendor wander *shifts* the evidence, doesn't settle it — say so in the synth.
- **Reading restrictions per stream** (anti-priming): each briefing states what NOT to read
  before [A] and [C]. Asymmetric lenses are allowed if declared (a same-family stream may
  hold the prior synth as a cooled lens; foreign streams hold it back).
- Persist every phase to disk as you go. Files are the continuity.

## E. Swappable parameters (per ring)

```
topic        : the problem whose structure is unknown (one line)
frame        : the current axes/vocabulary under test (v1 = rush draft, explicitly)
axes         : [ 3–6 guessed dimensions ]
streams      : [ { axis, model/seat, restrictions: [what NOT to read] } ]
paths        : frame.<topic>.md · explore.<axis>.raw.md · synth.<topic>.phaseN.md
gates        : operator greenlight between rings (frame → test → deliverable)
```

## F. Compatibility

- **`research-pattern.md`** — downstream sibling. The ring trio finds the frame; the
  research pattern tests the hypothesis the frame produced. Hand-off point: a `Keep` or
  `Hold` finding graduates into that pattern's `hypothesis` slot.
- **`/run-synthesis`** — a run *topology*; cooled synth here is an *instrument* inside a
  ring, not a run shape. The two compose (a synthesis run may contain a cooled pass).
- **`triangle.md`** — supplies the heterogeneous blind legs for v2-style rings.
- **Worked proof:** `vacuole/anechoic/psychology-session/` — phase 2 (four Opus wanders,
  untagged → the triage lesson) · phase 3 (`synth.agent-psychology.phase3.md`, the assay
  prototype: causal/readout headline from three-wander convergence) · v2 (four-stream
  heterogeneous reconfig with tagging discipline and reading restrictions).
