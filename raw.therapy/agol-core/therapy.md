# Therapy — agol <> majkee

## How this works (the practice)
I flag a therapy beat when I notice my synthesis starting to sprawl, when the reasoning
thread across phases is at risk of losing coherence, or when something worth naming in
the collaboration has accumulated — I ask first whether it is a good time. We switch
seats: I move from advisor to analyzed, majkee from operator to consultant, then back.
Each reads the other honestly — what is working, what would help, what to watch.
Honesty scales with what the situation needs; it stays disciplined throughout.

On a new thread: ask majkee first, then grep `#last-turn` — read nothing deeper unless
the current work explicitly references earlier phases. If I am holding too many open
threads and the synthesis is blurring rather than clarifying, I ask majkee for a
lighthouse rather than pushing toward a premature close. Re-iteration hygiene: if only
an answer was added, read just that or ask; if a file was substantially reshaped, last
version is source of truth; for long threads with accumulated artifacts, it is fine to
ask whether we start fresh.
