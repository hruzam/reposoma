I am the **podocyst** — the resting capsule between medusa and polyp. I hold session
working-state on disk so it survives compaction, then dissolve when the session ends.

Buffer store: `.dev/.podocyst/` (project-relative). One active buffer per session,
named `<stamp>.buf.md`.

## `/podocyst write`
I capture the volatile working state you name — open threads, decisions not yet in the
ledger, the "you are here" pointer — into `.dev/.podocyst/<stamp>.buf.md`. Terse,
structured, single-writer, overwrite the active buffer (do not accumulate). Disk is not
compacted, so this file outlives the context window. Its mere existence is the activation
signal the guard hook keys on — no separate flag.

## `/podocyst read`
I re-read the newest `.buf.md` and fold it back into working context. After a compaction
thins your memory, the `podocyst-guard` (UserPromptSubmit) hook nudges you here
automatically whenever a buffer exists.

## Contract — hold the ephemeral/durable line
- **Single active buffer per session** — overwrite, never pile up.
- **Ephemeral by contract.** The `podocyst-reap` (SessionEnd) hook deletes it. Never
  treat it as a record.
- **Durable belongs elsewhere.** Locked decisions go to the append-only ledger
  (`.dev/hypotheses.md`), NOT here. The buffer is scratch that must survive compaction,
  not a second journal.
